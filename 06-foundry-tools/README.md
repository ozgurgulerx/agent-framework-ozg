# 06 — Foundry Tools

This folder contains runnable, workshop-style examples focused on **Azure AI Foundry “tools”** integration patterns (tool hosting, tool governance, and agent-side tool usage).

## Samples
- `01-mcp-tool-via-ai-gateway/` — Wrap a REST API as an **MCP tool** behind a lightweight “AI Gateway”, use it from a **Foundry agent**, and add **governance** (auth, allowlist, approvals, audit logging).
